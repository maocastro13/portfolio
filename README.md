# Mauricio Castro — Portfolio

React 19 · TypeScript · Vite · Tailwind CSS 4 · react-three-fiber. Bilingual (EN/ES).

## Editing content

Everything shown on the site lives in [`src/data/content.ts`](src/data/content.ts).
Search for `TODO(mauricio)` to find what still needs updating. To update the CV,
replace `public/cv/Mauricio_Castro_CV.pdf` keeping the same file name.

## Commands

```bash
npm install
npm run dev      # local development
npm run build    # type-check + production build
```

## Deploy

Pushing to `master` builds the site and publishes it to the `gh-pages` branch
(`.github/workflows/deploy.yml`).
